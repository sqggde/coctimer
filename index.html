如何使用

1
在游戏中导出 JSON 数据
打开部落冲突，进入设置 → 导出游戏数据，将 JSON 文本复制到剪贴板。
2
点击「粘贴导入」粘贴 JSON
返回本工具，点击右上角的 粘贴导入 按钮，将 JSON 粘贴到输入框中。
3
自动显示所有升级项目及剩余时间
工具会自动解析数据，列出所有正在升级的建筑物、实验室项目、战宠等，并显示完成倒计时。
导入后数据会自动保存在本地，关闭页面也不会丢失。你还可以开启后台检测，在升级完成时收到通知推送。
